Seberapa luas redesign PortalSifast?

EmviUI-style (fresh, clean, Tailwind-based) — pilih cakupan dulu. Klik salah satu.

A

Shell + Theme saja

Sidebar, header, auth, welcome, token warna di app.css. ~20 file, dampak visual besar, risiko rendah. Halaman modul tetap layout lama tapi ikut warna baru.

B

Shell + halaman prioritas

Plus Dashboard, Login, Welcome, dan 1–2 modul utama (mis. Tickets / Monitoring). ~40–60 file. Recommended untuk look fresh tanpa rewrite seluruh portal.

C

Full redesign (~145 halaman)

Semua modul diseragamkan. ~230+ file. Paling konsisten, tapi lama dan mudah drift di tengah jalan.

Konteks cepat

Portal sekarang: Inertia React + shadcn + Tailwind v4, brand teal medis #0A9E8F, dark mode sudah ada. EmviUI = estetika Figma kit (clean surfaces, soft borders, modern spacing) — bukan copy paste file Figma.
